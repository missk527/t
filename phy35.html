Physics Chapter 35: Nuclear Decay

Alpha Decay

  1. An alpha particle is a helium nucleus.
  2. An alpha particle contains two protons.
  3. An alpha particle contains two neutrons.
  4. An alpha particle is the same as the nucleus of a helium atom.
  5. During alpha decay, the mass number decreases by 4.
  6. During alpha decay, the atomic number decreases by 2.
  7. The atomic number changes, so a new element is formed.
  8. Uranium-238 decays by alpha emission to form thorium-234.
  9. Radium-226 decays by alpha emission to form radon-222.
  10. In nuclear equations, mass numbers and atomic numbers must balance.

Beta Decay

  1. In beta decay, a neutron changes into a proton.
  2. A beta particle is a fast-moving electron.
  3. During beta decay, the atomic number increases by 1.
  4. During beta decay, the mass number stays the same.
  5. Carbon-14 decays by beta emission to form nitrogen-14.
  6. A beta particle has a mass number of 0.
  7. A beta particle has an atomic number of −1.
  8. The mass of a beta particle is almost zero.

Gamma Radiation

  1. Gamma radiation is pure energy.
  2. Gamma radiation has no mass.
  3. Gamma radiation has no charge.
  4. During gamma emission, no mass number or atomic number changes occur.
  5. Gamma emission may occur after thorium-234 is formed.
  6. Gamma radiation is represented using the Greek letter gamma, γ.

Neutron Emission

  1. In neutron emission, the nucleus emits a neutron.
  2. During neutron emission, the mass number decreases by 1.
  3. During neutron emission, the atomic number stays the same.
  4. Beryllium-9 can emit a neutron to form beryllium-8.

Comparing Nuclear Decay

  1. Alpha decay releases an alpha particle.
  2. Beta decay releases a beta particle.
  3. Gamma radiation releases electromagnetic energy.
  4. Alpha decay changes both the mass number and atomic number.
  5. Beta decay changes the atomic number but not the mass number.
  6. Gamma decay does not change the mass number or atomic number.
  7. The mass number is the total number of protons and neutrons.
  8. The atomic number is the number of protons.
  9. The atomic number is used to identify the new element formed.
  10. An alpha particle is written as 42He.
  11. A beta particle is written as 0−1e.
  12. A gamma ray is written as γ.
